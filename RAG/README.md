# RAG（Difyナレッジ用）

中延・二葉 雨水のたまりやすさマップのチャットが参照するナレッジ。**この README はナレッジに取り込まない。**

| ファイル | 内容 | 作り方 |
| --- | --- | --- |
| `01_地域の背景.md` | 立会川の谷と暗渠化、水害の歴史、令和7年9月11日の大雨、整備水準、10町丁目と暗渠の関係 | 手書き（元: `data/naisui_poc/04_llm_knowledge/region_background.md`） |
| `02_町丁目_<町丁目名>.md` ×10 | 町丁目ごとの概要、地形と暗渠、雨水がたまりやすい場所、公式の浸水想定区域、過去の浸水実績、注意点、避難所・土のう置場 | `tools/build_rag_markdown.py` で `town_facts.json` から生成（手で直さない） |
| `03_用語とデータの説明.md` | 分かること・分からないこと、回答のルール、用語、データの注意、出所とライセンス | 手書き |

## チャンクの作り方

- 1チャンク＝1つの話題。`##` の見出しから始め、見出しと本文に町丁目名や話題を必ず書く（検索で単独で取り出されても意味が通るように）。
- チャンクの中に空行を入れない。チャンクの間は空行1つで区切る。
- 1チャンクはおおむね500文字以内（2026-09-25時点の最長は `01_地域の背景.md` の出典の一覧で563文字、町丁目ファイルは409文字）。

## Difyでの推奨設定

- チャンク設定: カスタム（汎用）
- セグメント識別子（区切り文字）: `\n\n`
- 最大チャンク長: 1000文字（日本語で1チャンクが途中で切れない長さ）
- チャンクのオーバーラップ: 0（チャンクごとに話題が完結しているため）
- テキストの前処理: 「連続するスペース、改行、タブを置換する」はオフにする（チャンク内の改行を保つ）
- 検索: ハイブリッド検索（町丁目名・通り名などの固有名詞をキーワードで拾うため）、Top K は 5 程度

## 更新手順

モデルやデータを更新したら、町丁目の事実とRAGを作り直す。

```bash
UV="uv --system-certs run --with-requirements tools/requirements-surface-water-balance.txt python"
$UV tools/build_town_facts.py      # data/naisui_poc/02_processed/town_facts/ を更新
$UV tools/build_rag_markdown.py    # RAG/02_町丁目_*.md を更新
```

`01_地域の背景.md` と `03_用語とデータの説明.md` は、出典を確認したうえで手で更新する。
