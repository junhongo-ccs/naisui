# シナリオデータ

段階2の物理モデル、および段階3の代理AIモデルの学習・評価に使う降雨シナリオを保存する。

- 実測・予報の雨量データと、検証用の設計降雨は別ファイルにする。
- 降雨データには、時間間隔、単位、観測所または対象範囲、出所、取得日時を必須項目として記録する。
- 現行シナリオは、区の想定最大規模降雨（1時間最大雨量153mm、24時間総雨量690mm）である。実運用の予報ではなく、校正前モデルの比較用条件として明記する。

`rainfall_hyetograph.json` は、対象降雨・時間刻み・各時刻の雨量・境界条件を確定してから追加する。

`rainfall_scenario_template.csv` は、初期PoCの一律50mm/h排水能力モデルを確認するための説明用テンプレートである。`net_surface_water_mm_hr` が正なら地表貯留が増え、負なら残留水を排水できる余力を示す。負になった時点で地表水が即時に消えることは意味しない。

## 標準比較シナリオ

`rainfall_scenarios.csv` では、以下の1ケースだけを現行シナリオとして維持する。旧`sc_50mm_const`、`sc_80mm_peak`、`sc_100mm_extreme`は比較用の過去成果物であり、API・UI・新規実行には使わない。

| scenario_id | 位置づけ | 用途 |
|---|---|---|
| `sc_153mmh_24h_690mm_official` | 区の想定最大規模降雨 | 公式想定区域図との条件付き比較、およびチャットUIの現行表示 |

現時点の時間分布は、最大の連続1時間を153mm、残り23時間を各23.347826mm/hとして均等配分する暫定ハイエトグラフである。合計は690mmとなる。区・東京都が採用した正式な時間分布図を入手した時点で、同じ`scenario_id`の値を置き換えて再実行する。

このシナリオは設計・比較用であり、実運用の気象予報ではない。
