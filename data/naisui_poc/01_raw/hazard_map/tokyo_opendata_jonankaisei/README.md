# 城南地区河川流域浸水予想区域図（改定）浸水深・地盤高CSV（東京都オープンデータ）

## 概要

`docs/01_概要・計画/公開データ活用案.md`で提案されていた東京都オープンデータカタログ「浸水予想区域図（改定） 浸水深・地盤高」から、
品川区を含む**城南地区河川流域**分を取得したもの。想定降雨は本PoCが採用している
`sc_153mmh_24h_690mm_official`（時間最大153mm・総雨量690mm）と同一条件であり、
このCSVは2018年改定・2019年一部修正の「浸水予想区域図」（河川と下水道による浸水）に対応する。`../shinagawa_georeferenced.tif`の原典は2026年公表の「雨水出水浸水想定区域図」（下水道による浸水）であり、**同一図面の原典ではない**。降雨条件が一致しても、PDF派生ポリゴンの置き換えや直接のIoU評価に使わない。参照: [東京都下水道局の公表一覧](https://www.gesui.metro.tokyo.lg.jp/living/amesh/inundation)、[雨水出水浸水想定区域図Q&A](https://www.kensetsu.metro.tokyo.lg.jp/documents/d/gesui/usuisyussuiQA)。

## 未確認・要検証事項

- 測地系・座標系は原典仕様で未確認。2026-09-24の目視と概算変換ではTokyo Datum（EPSG:4301）仮定が有力だが、比較したPDFは別図面なので確定には使わない。詳細は`docs/04_GIS作業手順/品川_公式浸水深地盤高CSV_QGIS検証手順.md`。
- 「浸水深」欄が最大値かどうか、`0.00000000000`が「浸水なし」を表すか「データなし」を表すかは、カタログの説明文や図郭割PDF（`../` 内の `城南地区河川流域浸水予想区域図（改定）図郭割.pdf`、要別途取得）を確認すること。
- メッシュ中心点かどうか、隣接点間隔（メッシュサイズ）は、点群から実測して確認すること。
- `../jounan_jiban_shinsui_1.csv` / `_2.csv`（列構成が図郭No付きの5列で異なる、同カタログ内の旧リソース）とどちらが正とすべきかは未整理。本フォルダの2ファイルはカタログ上の名称に「改定」を含む方（その１・その２）を優先して採用した。
