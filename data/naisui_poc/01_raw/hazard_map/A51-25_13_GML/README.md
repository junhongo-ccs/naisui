# A51-25_13_GML の収録範囲

- 取得日: 2026-09-14
- 出典: 国土数値情報「雨水出水（内水）浸水想定区域データ（A51）」2025年度版
- 元ファイル: `../A51-25_13_GML.zip`
- 座標系: JGD2011（EPSG:6668）

## 重要

展開済みデータは `13218/A51-24_13218.geojson` ほか194面で、属性
`A51_004 = 13218` です。これは**福生市**のデータであり、対象地域の
品川区（市区町村コード `13109`）は含みません。

したがって、このファイルを中延・二葉PoCのIoU／Jaccard評価に使用しては
いけません。品川区を対象とする比較用ベクタは、東京都下水道局の城南地区
河川流域の公表資料、または品川区から公開される同等のGISデータを別途取得し、
収録範囲と想定降雨を確認してから `01_raw/hazard_map/` に配置します。

## 利用上の前提

A51は地方自治体が作成した浸水想定区域のGIS原典を面データ化したものです。
本PoCの50/80/100 mm/hシナリオとは降雨条件が異なるため、正解データとしての
精度評価ではなく、条件を明記した空間的な妥当性比較に限って扱います。
