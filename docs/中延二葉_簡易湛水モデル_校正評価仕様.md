# 中延・二葉 簡易湛水モデル — 校正・評価仕様

## 位置づけ

対象は、DEM・降雨・一律等価排水能力50mm/hを使う初期PoCの地表湛水スクリーニングモデルである。結果は避難判断・避難指示には用いない。

校正の目的は、実績浸水と公的ハザード情報に対して、危険箇所の抽出能力を改善することである。

## 評価指標

| 指標 | 定義 | 必要入力 |
|---|---|---|
| 実績地点の捕捉率 | 実績浸水地点のうち、モデル湛水セル（深さ閾値以上）に入る地点の割合 | 時刻・位置付き浸水実績ポイント |
| ハザード区域との重なり率 | モデル湛水区域と公的ハザード浸水区域の重なり。Jaccard係数を基本指標とする | ハザード区域ポリゴン |
| 町丁目順位の整合 | 町丁目ごとの最大・平均湛水深の順位と、実績被害件数または浸水深順位の整合 | 町丁目別実績（できれば時刻・深さ付き） |

## 入力ファイル

| ファイル | 置き場所 | 最低限必要な列・属性 |
|---|---|---|
| 実績浸水地点 | `data/naisui_poc/01_raw/records/inundation_points.csv` | `event_id, observed_at, longitude, latitude, depth_m, source` |
| ハザード区域 | `data/naisui_poc/01_raw/hazard_map/inland_flood_hazard.geojson` | 浸水区域ポリゴン、可能なら想定浸水深 |
| 町丁目境界 | `data/naisui_poc/01_raw/boundaries/r2kb13109.shp` | `S_NAME` |
| モデル出力 | `data/naisui_poc/02_processed/surface_water_balance/{scenario_id}/` | 最大・時刻別湛水深GeoTIFF、`risk_lookup` |

## 校正手順

1. 降雨イベントに対応する実績浸水地点・ハザード区域を同じCRSへ統一する。
2. `sc_50mm_const`、`sc_80mm_peak`、`sc_100mm_extreme` を基準として3指標を算出する。
3. 不一致を地点・町丁目・地形条件別に確認する。
4. 調整は次の順序を守る。
   1. 一律等価排水能力（初期値50mm/h）
   2. 地表流の移動率・流下方向ルール
   3. 必要性が確認された局所箇所だけ、個別排水能力または1D管網要素
5. 各変更について、入力値・出力値・3指標を保存し、校正前より悪化していないことを確認する。

## 解釈上の注意

- 町丁目集計の過去実績だけでは、実績地点の捕捉率や浸水深誤差は評価できない。
- PDFハザードマップを画像のまま重ねるだけでは、面積重なり率を再現可能に算出できない。GeoJSON等の区域データ、または検証済みのベクタ化が必要である。
- 一律排水能力モデルの湛水深は、個別地点の予報値ではない。校正後も、公式の避難情報を優先する。
