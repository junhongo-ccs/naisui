# 「発生～終息に至る内水氾濫観測結果にもとづくGISシミュレーションとエリア排水能力評価」要約

## 文書情報

- 著者: 鹿田 光一（東海大学 熊本教養教育センター）
- 英題: *Inland Flood Simulation and Estimation based on Field Observation*
- 主題: 現地観測を基にした、都市部の内水氾濫のGISシミュレーションと排水能力評価
- 元資料: [C52.pdf](C52.pdf)

## 要旨

本研究は、2016年6月20日から21日にかけて発生した内水氾濫を対象に、発生から終息までの現地観測結果をGISで解析した事例研究である。内水氾濫は集中豪雨後に急に発生し、数時間で収まることが多いため、現象全体の把握が難しい。本研究では、雨量と浸水深の時系列観測、5mメッシュの標高データ（DEM）を用いて集水域・浸水範囲・浸水量を推定し、地域の排水能力が時間とともに変化する可能性を検討した。

## 背景と目的

- 集中豪雨の頻発化と土地利用の変化により、都市部の内水氾濫の規模・影響は深刻化している。
- 内水氾濫は発生までの時間が短く、短時間で終息するため、発生機構や排水過程を観測・把握しにくい。
- 対象地域では、豪雨時に南部の道路が広く冠水し、病院へのアクセス道路が通行不能となるなど、生活・救急機能に影響が生じていた。
- 本研究の目的は、現地観測を基に内水氾濫の時間変化をGISで再現し、エリア全体の排水能力を評価することである。

## 内水氾濫の捉え方

本研究では、内水氾濫を **「集水域の排水能力が不足し、地表水が地形に沿って集積した状態」** と定義する。対象となる地表水は、地表面を経由して河川等へ向かう一つの水系を形成するものとした。

## 観測内容

| 項目 | 内容 |
| --- | --- |
| 対象事象 | 2016年6月20日深夜から21日未明の集中豪雨に伴う内水氾濫 |
| 雨量 | 熊本県統合型防災情報システムの10分間隔雨量データ |
| 浸水深 | 観測地点（マンション入口）で時系列に記録 |
| 現地状況 | 浸水の発生・拡大・収束を観察 |

観測では、降雨のピークを過ぎた後、時間差を伴って急激な浸水が発生した。これは、降った雨が集水域から低地へ集まり、排水能力を超えた後に浸水として表れることを示している。

## GISによる解析手法

国土地理院の **5mメッシュDEM** を使い、ArcGISで次の処理を行った。

```text
DEM（標高データ）
  ↓
地表面の平滑化
  ↓
流向・流域・累積流量ラスタの作成
  ↓
浸水域へ流入する集水域の抽出
  ↓
実測浸水深を基に浸水範囲・浸水量を算出
```

浸水量は、GISのサーフェス体積計算を用いて求めた。2016年6月20日23時30分と翌21日3時の状況を含め、発生から終息までの浸水量の時間変化を推定している。

## 主な結果

- 現地で観測した浸水深を基に、集水域、浸水分布、浸水量をGIS上で推定できた。
- 浸水深は時間とともにおおむね直線的に低下した一方、浸水量の変化からみると、排水能力は浸水深の回復に伴って低下する傾向が示された。
- 都市部では建物が視界を遮るため、面的な浸水分布を直接観測することは難しい。しかし、目視で確認できた範囲では、GISシミュレーションは妥当な浸水状況を示したと評価している。

## 課題と今後の方向

- 降雨後に時間差を伴って急激に浸水し、浸水深の低下に伴って排水能力が変化する仕組みを、十分には解明できていない。
- 突発的な浸水により、発生初期の観測データが不足した。
- 異なる降雨パターンでの浸水の有無・時間変化を集め、検証を重ねる必要がある。
- 数平方キロメートルに及ぶ市街地の浸水範囲・浸水深を、時間変化も含めて効率よく計測する手法の確立が課題である。

## 実務への示唆

現地観測、DEMに基づく集水域解析、浸水量の推定を組み合わせることで、下水道情報が十分に得られない場合でも、内水氾濫の危険箇所や排水上の課題を把握する手がかりになる。特に、病院・学校・主要道路などの重要施設へのアクセスが途絶するリスクを、地域防災や排水対策の優先順位付けに活用できる。
