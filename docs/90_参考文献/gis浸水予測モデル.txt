# GISを用いた浸水予測モデル

## これは何か

GISを用いた浸水予測モデルは、地形・下水道・降雨などのデータをデジタル地図上で重ね合わせ、豪雨時に **「どこに、どの程度の水が溜まるか」** をシミュレーションして地図として示す仕組みです。

主な対象は、雨水が下水道や排水路の処理能力を超えて市街地にあふれる **内水氾濫** です。危険箇所の把握、排水施設の整備計画、避難判断や防災対策に活用されます。

---

## 全体の流れ

```text
地形・土地利用・下水道・降雨のデータ
                 ↓
  雨水の流れ、浸透、排水能力を計算
                 ↓
  あふれた水の広がりと浸水深を計算
                 ↓
  危険箇所・浸水深を地図で可視化
```

## 4つの解析ステップ

| ステップ | 行うこと | 分かること |
| --- | --- | --- |
| 1. 地形を解析する | 標高データから、水が流れる方向と集まりやすい場所を計算する | 低地、水の通り道、雨水が集まりやすい場所 |
| 2. 降雨・浸透・流出を計算する | 降った雨を、地面に浸透する水と地表を流れる水に分ける | 地表に流れ出す雨水の量 |
| 3. 下水道の排水能力を計算する | 下水管の太さ・勾配、ポンプ能力などから管内の流れを計算する | 排水できる量、満管・溢水が起きる場所 |
| 4. 地表の氾濫を解析する | 下水道からあふれた水が地表でどのように広がるかを計算する | 浸水範囲、浸水深、影響を受ける建物・道路 |

### 1. 地形を解析する

国土地理院などの **標高データ（DEM: 数値標高モデル）** を、細かな格子状のメッシュとしてGISに取り込みます。各地点の標高を比較して、高い場所から低い場所へ水が流れる方向を求めます。

さらに、上流側からどれだけの水が集まるかを示す **累積流量** を計算します。これにより、雨水が集まりやすい低地や流路を特定できます。

### 2. 降雨・浸透・流出を計算する

降雨は、すべてが地表を流れるわけではありません。土地利用や地表の状態に応じて、次のように分けて扱います。

- **地下浸透**: 土地や緑地などに染み込む水
- **表面流出**: アスファルト・建物などにより浸透せず、地表を流れる水

舗装面や建物が多い市街地では表面流出が増えるため、内水氾濫のリスクが高くなります。

### 3. 下水道・排水設備を計算する

地表を流れた水は、雨水ますや側溝を通じて下水道管へ流入します。モデルでは、管の直径・勾配・接続関係・ポンプの能力を用いて、下水道が排水できる量を計算します。

豪雨で下水管が満管になると、排水しきれない水がマンホールや雨水ますから地表へあふれる **溢水** も再現します。

### 4. 地表の広がりと浸水深を計算する

地表へあふれた水が、地面の勾配、道路、周辺の地形に沿って広がる様子を二次元的に計算します。結果として、次の情報を地図や3D表示で確認できます。

- 浸水が想定される範囲
- 各地点の浸水深（例: 数cm、数十cm）
- 影響を受ける建物、道路、避難経路

## 水収支: 浸水が起きる基本条件

モデルの基本は、水の出入りを比べる **水収支** です。

| 区分 | 内容 |
| --- | --- |
| 流入量（増える水） | 対象地域に直接降る雨 + 周辺から地表を流れ込む水 |
| 排出量（減る水） | 下水道などから排出される水 + 地面へ浸透する水 |

```text
流入量（降雨 + 表面流入）
    >
排出量（下水道排出 + 地下浸透）
    → 処理しきれない水が地表に残り、浸水・氾濫が生じる
```

つまり、雨水が流入・発生する量が、浸透と排水で処理できる量を上回ると浸水が発生します。

---

## モデルに必要な主なデータ

| データ | 用途 |
| --- | --- |
| 標高データ（DEM） | 流向、低地、集水域、地表での水の広がりを求める |
| 降雨データ | 雨量と時間変化を与える |
| 土地利用・地表面データ | 浸透しやすさ、表面流出のしやすさを設定する |
| 下水道管・排水施設データ | 排水能力、満管、溢水地点を計算する |
| 観測水位・浸水実績 | モデルの検証と補正に用いる |

## 最近の発展

### AI・機械学習

物理モデルは詳細な計算ができる一方、計算に時間を要することがあります。深層学習などのAIを使うと、過去のシミュレーション結果や観測データを学習し、短時間で浸水リスクを推定できます。物理モデルとAIを組み合わせることで、速度と信頼性の両立が期待されます。

### リアルタイム観測とデータ同化

雨量レーダー（例: XRAIN）や水位センサーの観測値を計算中のモデルに取り込み、予測を随時補正する方法です。観測網を活用することで、数時間先の浸水・洪水リスクをより精度よく把握できます。

---

## 活用時の注意点

- 予測結果は、標高・下水道・土地利用・降雨データの精度に左右されます。
- 局地的な豪雨や短時間の強雨は、雨量観測地点との距離によって誤差が大きくなることがあります。
- モデルは危険度の把握や対策検討のための支援情報であり、実際の避難判断では気象警報、河川情報、自治体の避難情報と併用します。
