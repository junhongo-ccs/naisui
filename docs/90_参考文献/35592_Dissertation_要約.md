# 「AIモデルと水理モデルのハイブリッド活用による洪水予測技術の高度化に関する研究」要約

## 文書情報

- 著者: 渡辺 健
- 学位: 博士（工学）、大阪大学大学院工学研究科 地球総合工学専攻
- 学位授与: 2026年3月25日
- 論文題目: AIモデルと水理モデルのハイブリッド活用による洪水予測技術の高度化に関する研究

## 要旨

本論文は、洪水予測における **AIモデル** と **物理に基づく水理・水文モデル** の長所を統合するハイブリッド手法を開発・改良した研究である。AIは高速で高精度な予測が期待できる一方、十分な学習データを必要とし、未経験規模の豪雨には弱い。物理モデルは観測データが比較的少なくても構築でき、未経験豪雨にも適応しやすいが、計算量や予測精度に課題がある。本研究は両者を組み合わせ、河川水位の予測精度、リアルタイム運用性、多地点観測データの活用を高めることを目指した。

## 背景と目的

気候変動に伴い洪水災害が激甚化する中、避難判断や水防活動には数時間先よりも長いリードタイムでの高精度な洪水予測が求められる。本論文の目的は、次の2種類のモデルを対象に、実用的なハイブリッド化を進めることである。

| 対象 | 目標 |
| --- | --- |
| 降雨流出予測モデル | 特定地点の河川水位予測の精度向上と実用性向上 |
| 河道モデル | 河川縦断の水位予測と、多地点水位データ同化の高度化 |

## 研究の中核

### 1. RRIモデルと深層学習の統合

分布型流出モデルである **RRI（Rainfall-Runoff-Inundation）モデル** の計算流量を、深層学習モデルの入力に取り込んだ。

- 上流側の各小流域について算出した流出量を入力することが、予測精度の向上に有効だった。
- RRIモデル単体の流出予測精度は、最終的なAI予測への影響が比較的小さいことが分かった。
- DNN（深層ニューラルネットワーク）の構造を改良し、一般的なDNNより高い予測性能を示した。
- RRI固有の性質に依存しない知見であり、既存の流出解析モデル資産を利用した展開が期待できる。

### 2. リアルタイム運用への適用

ハイブリッドモデルを実務のリアルタイム予測に使うため、軽量化と観測欠損への耐性を検討した。

- 複数地点を同時に予測する方式へ拡張しても、単独モデルより有意に高い精度を維持した。
- 複数流域が合流する下流域で、ハイブリッド化の効果が特に大きいことが示唆された。
- 欠損を模擬したデータで学習させることで、実際に水位観測データが欠損した際の精度低下を抑えられた。

### 3. PINNsによる河道モデルとデータ同化

河川縦断の水位を扱う河道モデルには、物理法則を学習に組み込む **PINNs（Physics-Informed Neural Networks）** を適用した。

- 一次元不定流式を対象に、横流入と一般断面を含む条件で順解析できるようPINNsを改良した。
- 既往洪水の波形に対し、安定して適切な解に収束できた。
- 実河川の既往出水事例を用いた多地点水位データ同化・逆解析では、区間ごとの粗度係数を精度よく推定できた。
- 計算時間は同化する地点数の影響をほとんど受けず、将来の水位センサー増設にも対応しやすい。

## 結論と意義

本論文は、AIの高速性・予測性能と、物理モデルの頑健性・外挿性を組み合わせることで、洪水予測技術を高度化した。特に、既存の流出モデルをAIの入力として活用する方法、データ欠損に強いリアルタイム予測、多地点水位観測を効率よく取り込むPINNsベースの河道モデルを示した点に意義がある。

今後、河川モニタリングのセンサー網が拡充した際には、本手法により縦断水位予測と洪水リスク把握の精度向上が期待される。早期避難判断や水防活動を支える実務技術としての応用可能性が高い。
