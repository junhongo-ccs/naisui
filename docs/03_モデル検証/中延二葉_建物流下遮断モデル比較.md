# 中延・二葉 建物による流下遮断の比較（PLATEAU導入計画 フェーズ2）

作成日: 2026-09-25  
対象: 採用モデル（土地利用反映版 `plateau2025_v1_base`）、降雨シナリオ `sc_153mmh_24h_690mm_official`  
計画: `docs/01_概要・計画/PLATEAU導入計画.md`（4章フェーズ2、5章評価設計）

## 1. 結論

- 建物セルへの流入と貯留を止めると、湛水面積は採用版より24〜37%減り、町丁目の面積比は1〜2組の順位が入れ替わる。
- 実績との順位相関は、建物セルとみなす閾値によって変わる。閾値0.3・0.5ではR7.9.11で上がり（+0.436→+0.479）31年累計で下がる（+0.333→+0.250）。閾値0.7では両方とも上がる（R7.9.11 +0.528、31年累計 +0.450）。
- 実績の2種類で向きがそろうのは閾値0.7だけで、結論が閾値に依存する。計画 2.1節の基準（感度分析と両方の実績で同じ向き）を満たさないため、**改善とは言えない**。
- 二葉二丁目（モデル9位・実績3〜4位）の食い違いは、建物を入れるとむしろ広がる（面積比0.68%→0.30%）。

**判断（案）**: 採用パイプラインは土地利用反映版（`plateau2025_v1_base`）のままとし、建物による流下遮断は採用しない。実行経路（`--building-fraction-raster`）と結果は残す。採否はユーザーが決める。

## 2. 方法

`tools/run_pysheds_surface_routing.py` に `--building-fraction-raster` と `--building-threshold` を追加した。フェーズ1の格子化で作った「建物・屋根」の面積割合（`surface_fraction_plateau2025_v1.tif`）が閾値以上のセルを建物セルとし、次のように扱う。

1. **流入回避**: 各セルの流下先を、整形DEMで厳密に低い建物以外の隣接セルのうち最も急な方向へ付け替える。屋根に降った雨も、低い地面・道路のセルへ流れる。該当するセルが無い場合は元の流下先（建物セル）を残す。
2. **貯留不可**: 建物セルの窪地容量を0にする。

DEMを建物の高さでかさ上げする方法は採らなかった。約3.9mの格子では建物の隙間が消えて中庭が閉じた窪地になり、実在しない深い湛水を作るためである。

流出係数は採用版と同じ（標準係数）。道路の低部・縁石の扱いは入れていない。

### 2.1 点検

| 項目 | 結果 |
| --- | --- |
| 回帰（新しい引数を使わない場合） | 採用版の出力（GeoTIFF 30枚、水収支）とビット単位で一致 |
| 水量保存（前ステップ貯留＋流入−排水−域外流出＝貯留） | 全ステップで残差の最大は約3×10⁻⁹m³（総流入約146万m³） |
| 建物セルの割合（閾値0.3／0.5／0.7） | 49%／41%／31% |
| 建物へ流れ続ける建物以外のセル | 約2.3万〜3.0万セル（建物以外のセルの2.6〜4.4%）。低い建物以外の隣接セルが無いもので、格子の粗さによる近似の限界 |
| 対象町丁目内の最大深 | 6.37mで不変（既知のDEMアーティファクト）。二葉一丁目は閾値0.5・0.7で3.98m→2.35mに減少。格子全体の最大深は閾値0.7で7.32m→7.47m（対象町丁目外） |

## 4. 解釈

1. 建物を流下の障害にすると、屋根の雨が道路・地面へ集まるため、二葉一丁目のような道路沿いの窪地で湛水が増え、建物の下にあった地形上の窪地（中延三丁目の一部など）では減る。この変化はR7.9.11の傾向と合う方向である。
2. 一方で、建物の下の窪地容量を一律に除くことで、建物が密集した町丁目（中延五丁目、二葉二丁目）の面積比が下がる。国土地理院DEM5Aは建物を除いた地表面なので、建物の下の窪地は実在の地形だが、建物がある以上そこに水はたまらない。この扱い自体は妥当だが、除いた水がどこへ行くかは単純D8の近似に依存する。
3. 閾値による結果の違いは、主に中延五丁目と二葉四丁目の順位による。n=10ではこの1〜2町丁目の差が相関を大きく動かす。

## 5. 計画の採用条件との対照

| 採用条件（計画 5章） | 結果 |
| --- | --- |
| 入力の出所・変換・パラメータが再現可能 | 満たす（本書、各 `run_metadata.json`） |
| R7.9.11を含む評価で現行（採用版）より悪化しない | 満たす（全閾値で+0.04〜+0.09） |
| 既知のDEMアーティファクトや境界の影響を増幅しない | 対象町丁目内では満たす。格子全体の最大深は閾値0.7でわずかに増加 |
| 結論が特定の恣意的パラメータだけに依存しない | 満たさない。31年累計との相関の向きが閾値で変わる |

## 6. 次の選択肢

1. **採用版（v1_base）を維持し、建物遮断は保留する**（推奨）。
2. **閾値0.7の建物遮断を採用する**。両方の実績で相関が上がる唯一の設定だが、閾値の選択に根拠が無い（結果を見て選ぶことになる）。
3. **道路の扱いを加える**（計画 4章フェーズ2の後半）。道路セルの標高を縁石相当だけ下げ、流れを道路に集める。二葉二丁目の食い違いの説明にはつながる見込みが薄い。
4. **地形側を調べる**。二葉二丁目・中延三丁目の食い違いの原因（DEM、窪地容量、上流集水面積）を調べる。
