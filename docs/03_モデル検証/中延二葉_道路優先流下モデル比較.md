# 中延・二葉 道路への優先流下の比較（PLATEAU導入計画 フェーズ2）

作成日: 2026-09-25  
対象: 採用モデル（土地利用反映版 `plateau2025_v1_base`）、降雨シナリオ `sc_153mmh_24h_690mm_official`  
計画: `docs/01_概要・計画/PLATEAU導入計画.md`（4章フェーズ2、5章評価設計）  
関連: `docs/03_モデル検証/中延二葉_建物流下遮断モデル比較.md`（建物による流下遮断）

## 1. 結論

- 雨水を低い道路セルへ優先して流すと、実績との順位相関は採用版より上がる（R7.9.11 +0.436→+0.528、31年累計の率 +0.333→+0.367）。
- この結果は、道路セルの閾値（0.3／0.5）で変わらない。流出係数の感度（下限・上限・住宅敷地を緑地とみなす設定）でも、道路の有無で相関が下がる設定は無く、4設定中3設定で両方の実績との相関が上がった（上限の設定は変化なし）。
- 建物による流下遮断と違い、感度分析と両方の実績で同じ向きの結果が得られた。計画 2.1節の「改善」と表現できる条件を、n=10の範囲で満たす。ただし差は+0.03〜+0.09で、統計的に有意な差ではない。
- 貯留体積・湛水面積の変化は2%以内で、水の量はほとんど変わらず、湛水の位置が道路沿いへ移る。
- 建物遮断と組み合わせると、結果は再び建物の閾値に依存する（閾値0.5では31年累計との相関が下がる）。

**判断（2026-09-25、ユーザー決定）**: 道路優先（閾値0.5、建物遮断なし、`plateau2025_v3_road050`）を**採用パイプライン**とした。バックエンドの `PIPELINE_DIR`、地図オーバーレイ、画面・回答の注記（道路へ優先して流す仮定）を切り替えた。差は統計的に有意ではないため、説明では「実績との整合がわずかに上がった（n=10）」にとどめ、「精度が証明された」とは表現しない。建物遮断は採用しない。

## 2. 方法

`tools/run_pysheds_surface_routing.py` に `--road-fraction-raster` と `--road-threshold` を追加した。フェーズ1の格子化で作った「道路・舗装」の面積割合（`surface_fraction_plateau2025_v1.tif`。土地利用の道路用地のうち建物外の部分）が閾値以上のセルを道路セルとする。

- 各セルについて、整形DEMで厳密に低い隣接セルに道路セルがあれば、そのうち最も急な方向へ流す（道路上の水は道路に沿って流れ、宅地の水は隣の道路へ出る）。
- 低い道路セルが無いセルは、pyshedsの元の流下先を変えない。
- 地形（DEM）と窪地容量は変えない。偽の窪地を作らないため、縁石の高さだけ道路を下げる方法は採らなかった。

流下先は常に整形DEMで低いセルなので、計算順序が保たれ、循環は生じない。

## 4. 解釈

1. 道路優先は、屋根・宅地の水を隣の道路へ出し、道路に沿って低い所へ運ぶ。水の総量はほぼ同じで、湛水の位置が道路沿いの低地へ移る。二葉一丁目のように道路沿いの低地がある町丁目の面積比が上がり、宅地内の窪地が多い中延三丁目・二葉四丁目は下がる。
2. 地形・窪地容量を変えないため、建物遮断のように建物の下の窪地容量を一律に除く大きな変化が無く、閾値や係数に対して結果が安定している。
3. 道路の雨水ますや側溝による排水（道路の排水能力が宅地より高いこと）は表現していない。排水能力は全セル一律50mm/hのままである。
4. 約3.9mの格子では幅4m未満の路地は道路セルになりにくく、路地沿いの流れは表現されない。

## 6. 次の選択肢

1. **道路優先（閾値0.5）を採用パイプラインにする**（推奨）。バックエンドの `PIPELINE_DIR`、地図オーバーレイ、画面の注記（道路へ優先して流す仮定を追加）を切り替える。
2. 採用版（v1_base）を維持し、道路優先は検証結果として残す。
3. 道路の排水能力を宅地より高くする扱いを試す（根拠となるデータが無いため、感度分析としてのみ）。

## 7. 再現手順

```bash
UV="uv --system-certs run --with-requirements tools/requirements-surface-water-balance.txt python"
P=data/naisui_poc/02_processed; SC=sc_153mmh_24h_690mm_official; F=$P/model_input/surface_fraction_plateau2025_v1.tif
$UV tools/run_pysheds_surface_routing.py --scenario-id $SC \
  --dem $P/pysheds_surface_routing/sc_100mm_extreme/dem_raw_epsg3857.tif \
  --runoff-coefficient-raster $P/model_input/runoff_coefficient_plateau2025_v1_base.tif \
  --road-fraction-raster $F --road-threshold 0.5 \
  --output $P/pysheds_surface_routing_roads/plateau2025_v3_road050
# 組み合わせ: --building-fraction-raster $F --building-threshold 0.5 等を追加
# 係数の感度: --runoff-coefficient-raster を runoff_coefficient_plateau2025_v1_low / _high / plateau2025_v1_yardsgreen_base に替え、
#             出力を plateau2025_v3_road050_coef_<low|high|yardsgreen_base> とする
$UV tools/export_risk_lookup.py --towns data/naisui_poc/01_raw/boundaries/r2kb13109.shp \
  --scenario-dir $P/pysheds_surface_routing_roads/plateau2025_v3_road050/$SC
$UV tools/evaluate_model_against_records.py --output-dir $P/pysheds_surface_routing_roads/comparison_$SC \
  --labels uniform adopted_v1 ... --risk-lookup <各 risk_lookup JSON>
```
