# 中延・二葉 100mm/hシナリオ — 初期定性比較

## 対象

- モデル: `sc_100mm_extreme`（一律等価排水能力50mm/h、10分刻み、30分）
- 比較対象: 品川区防災地図「雨水出水浸水ハザードマップ」（下水道からの氾濫・内水氾濫）
- 目的: 校正前に、危険箇所の水が集まる傾向を捉えられているかを定性的に確認する。

## 確認結果

**判定: 現時点では局所的な危険箇所の抽出は不十分。**

品川区のハザードマップは、浸水想定区域を局所的な色付き区域として示している。一方、現行の100mm/h結果は、約4.78mセルの解析範囲ほぼ全体で1cmを超える湛水となった。

| 指標 | 現行100mm/h結果 |
|---|---:|
| 最大湛水深 | 約0.052m |
| 1cm超湛水面積 | 約29.9km² |
| 解析範囲に対する1cm超の割合 | ほぼ100% |

そのため、このモデルは「100mm/hが50mm/hの等価排水能力を上回ると、地表に余剰水が生じる」という水収支の確認には使えるが、ハザードマップにある低地・線路沿い・局所的な排水ボトルネックを選別できていない。

## 原因の仮説

1. 全セルに同一の余剰降雨を与えているため、地形差が現れる前に全域で湛水が発生する。
2. 地表流は各10分コマで湛水の一部を隣接低セルへ移すだけであり、集水域からの流入・くぼ地への集積を十分表せない。
3. 排水能力が一律であり、雨水ます、管路、鉄道・道路の低部などの局所的な排水差を表現していない。

## D8流向の試行結果（採用前）

DEM由来のD8流向と集水量を導入し、1時刻内で複数回流下させる試行を行った。全域一様の湛水は減ったが、DEMの微小な閉塞凹地に水が集中し、100mm/hケースで最大約12mの湛水深が発生した。

この値は採用しない。D8方向だけでは、凹地からの越流経路、道路・下水道への排水、凹地の貯留容量を表せないためである。微細DEMをそのまま使うと、数セル規模の窪みに流域全体の水が閉じ込められる。

## 校正の順序

1. **一律等価排水能力**を感度分析する。ただし一律値だけでは局所差を再現できないことを同時に確認する。
2. **地表流ルール**を改善する。まずPriority-Flood等で凹地を水文学的に補正し、流向・集水量・越流経路を導出する。その上で凹地貯留は容量・越流しきい値を持たせ、1ステップ当たりの移動率だけに依存しない集積処理を導入する。
3. ハザード区域・実績地点と比較し、局所的に外れる箇所のみ排水能力の空間差または1D管網要素を追加する。

## 次の定量評価に必要なもの

- 浸水想定区域のGeoJSON/Shapefile、または位置合わせを検証済みのベクタ化データ
- 緯度経度・時刻・可能なら浸水深を持つ実績浸水地点

PDF画像だけを重ねる確認は定性的な参考に留める。Jaccard係数など再現可能な評価には、同一座標系のベクタ区域が必要である。

## 安全上の扱い

本結果は校正前のスクリーニングに限定する。避難判断、避難所の安全判定、個別地点の浸水深予報に使用しない。
