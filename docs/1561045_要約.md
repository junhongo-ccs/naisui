# 「GISを利用した内水氾濫の危険予測および検証」要約

## 文書情報

- 資料: 2018年度卒業研究概要
- 題目: GISを利用した内水氾濫の危険予測および検証
- 著者: 久保 昌也（史 中超 研究室）
- 対象地域: 神奈川県横浜市港北区高田西一丁目

## 要旨

本研究は、集中豪雨で生じる**内水氾濫**（雨量が都市の排水・処理能力を上回って発生する浸水）について、GISと水文解析を用いて危険箇所を予測し、実際の浸水被害と照合したものである。標高、下水管、土地利用、地下浸透能力を組み合わせたモデルにより、浸水箇所を一定の精度で再現できた一方、局地的・短時間の豪雨を十分に表せないことが課題として示された。

## 背景と目的

- 近年、1時間に50mmを超える集中豪雨が増え、都市化に伴う地表面の変化も浸水被害を増やしている。
- 浸水には、河川の増水による外水氾濫と、排水能力を超えた雨水による内水氾濫がある。
- 全国の水害被害額は2015年に3,850億円に達し、1994年から2003年までの内水による被害額は約1.2兆円（全体の48%）だった。
- 高田西一丁目を対象に、内水氾濫被害予測モデルで浸水箇所を予測し、実績被害と検証することを目的とする。

## 手法

ArcGISで標高データを収集・変換し、雨水の流れを解析した。各セルへの累積流量を求め、周辺の1町丁分の雨量が流入する箇所を特定することで、雨水が溜まりやすい場所を把握した。

予測モデルでは、次の4要素を扱う。

| 要素 | 内容 |
| --- | --- |
| Q1 | 対象町丁に降る降水量 |
| Q2 | 周辺からの表面流入量 |
| Q3 | 下水道による雨水排出量 |
| Q4 | 地下浸透量 |

`Q1 + Q2 > Q3 + Q4` となるときの水量から、内水氾濫が発生し得る最小の降雨強度を求めた。入力データには標高、下水管、土地利用、地下浸透能力を用いた。

## 結果と検証

- 2004年10月20日の集中豪雨を対象に被害予測を実施した。
- 予測された管渠・地域と実際の浸水被害箇所の一致率は **86.6%** だった。
- 実際に被害が発生した地点を高い確率で捉えられた一方、被害が起きていない地点を浸水ありとする誤予測も見られた。

## 課題と示唆

- 雨量計測所と対象地が約3km離れており、局地的な降雨量との差が誤差につながった可能性がある。
- 最大1時間雨量による計算では、数分間で大量に降る局地的豪雨を適切に反映しにくい。
- 今後は、より正確な降雨状況の取得と、分単位の予測モデルが必要である。
- 被害軽減には、地下浸透施設の整備と下水道の処理能力向上が重要と結論づけている。
