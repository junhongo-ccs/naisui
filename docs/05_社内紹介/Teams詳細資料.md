**中延・二葉 雨水のたまりやすさマップ（内水氾濫 AI・GIS PoC）**

**▶ マップ（AIチャット付き）**: https://naisui.vercel.app 　※PC推奨（スマホはチャットのみ表示）
**▶ 説明ページ（計算手順・照合結果・技術の全体）**: https://naisui.vercel.app/about.html

対象: 品川区 中延一〜六丁目・二葉一〜四丁目（10町丁目）
作成期間: 2026年9月14日〜29日
本資料は要点のみ。数式・パラメータ・経緯の詳細は説明ページを参照。

> 平時に地域を知るためのPoC。浸水の予報や現在の状況を伝えるものではなく、避難の判断や道路の通行可否には使用不可。

**1. 対象地域の選定理由**

- 立会川の谷沿いの町。立会川は昭和44〜47年に暗渠化され、現在は下水道幹線（立会川幹線）、上部は立会道路
- 令和7年9月11日の大雨（品川区付近で1時間約120mm）では、10町丁目のうち浸水報告の多い上位6町丁目がすべて暗渠の通る町。報告の少ない4町丁目はすべて暗渠の通らない町
- 河川整備の目標は1時間50mm規模の降雨。これを大きく超える雨で谷底のどこに水がたまるかを、地図上で確認することが目的

**2. 地図の2つのレイヤー**

凡例のチェックで表示を切り替え、東京都の雨水出水浸水想定区域図と自前の試算を比較可能。配色は浸水想定区域図が青灰、試算が紫。

- **東京都「城南地区河川流域 雨水出水浸水想定区域図」**: 想定最大規模の大雨（153mm/h・690mm/24h）による浸水の範囲と深さを示す東京都の公式の想定。面的な浸水深のデータとして唯一の公式資料であり、試算を見る際の基準。配布形式がPDFのみのため、QGISでジオリファレンス（GCP 5点・線形変換、RMSE 約4.5m、EPSG:6677）。凡例から採取したRGBで浸水深5段階をラスタからベクタ化。ジオリファレンスの残差として数mのずれあり（最大残差 約7.8m）
- **雨水がたまりやすい場所（試算）**: 同じ降雨で最大湛水深が1cm以上となるセル。深いほど濃く表示

避難所・土のう置場は品川区の公開情報から記号で表示（住所は国土地理院 住所検索APIで座標化）。記号の押下で名前・住所、土のう置場は袋の数も表示。

**3. 試算モデル（地表流のスクリーニング）**

下水道管網の水理計算は対象外。DEM上の地表流と一律の排水により、「排水しきれない雨水がどこにたまるか」を見るモデル。

1. **DEM**: 国土地理院 標高タイル DEM5A（z15）のモザイク。1セルは地上で約3.88m四方。面積・体積は地上面積で計算（Web Mercatorの見かけの面積では約1.52倍の過大）
2. **流向・凹地**: pyshedsでpit・depressionの埋め立てと平坦部の解消を行い、D8流向を算出。埋め立て前後の標高差を各セルの凹地貯留容量とする
3. **流出係数**: PLATEAU 2025の土地利用・建物からセル単位で割当て。建物0.90、道路0.85、その他の不浸透面0.80、緑地0.20、鉄道敷など1.00（対象範囲の平均0.81）。各区分で±0.05〜0.10の感度分析を実施
4. **降雨**: 12時間目に153mm/h、残り537mmを23時間に均等配分（約23.3mm/h）。時間配分は暫定
5. **排水**: 管路は含めず、全セル一律に50mm/h相当の排水能力を仮定。たまった水も毎ステップ50mm/h相当ずつ排水
   `excess = max(0, rain_rate × C − 50mm/h) × Δt` （Δt = 10分、24時間分）
6. **流下**: D8で下流へ1ステップ1ホップずつ送水。凹地は容量まで貯留し、超過分をさらに下流へ。隣接セルに自セルより低い道路セル（道路・舗装の面積比0.5以上、全セルの約19%）があれば優先して流下（宅地の雨水が側溝に集まることの反映）。建物による流れの遮断はなし
7. **集計**: 24時間の最大湛水深を地図に表示。町丁目単位では深さ20cm以上の面積比で5区分（0%／0.3%未満／0.6%未満／1.2%未満／1.2%以上）

**4. 実績との照合**

実績による校正（パラメータの合わせ込み）は未実施。区の町丁目別浸水実績は、町丁目の順位の一致を確かめる検証にのみ使用（Spearmanのρ。R7.9.11はn=10、31年累計は中延一丁目のデータがないためn=9）。

- 当初は町丁目のリスクを「最大の深さ」で判定し、実績と逆相関（ρ=−0.30）。「20cm以上の面積比」への切替えで実績と同じ向きに
- 土地利用反映版: R7.9.11の件数と +0.436、31年累計（率）と +0.333
- 道路優先流下版（採用）: +0.528／+0.367
- 町丁目数が少なく差は統計的に有意ではないため、評価は「整合がわずかに向上」にとどめる。道路の閾値（0.3／0.5）や流出係数を変えても、道路優先流下で相関が下がる設定はなし

**5. AIチャット（ガードレール付きRAG）**

地図の読み取りを補助するチャット。LLMにすべてを答えさせず、危険な質問はLLM呼び出しの前段で遮断。

```
React → FastAPI（決定的な判定）→ Difyチャットフロー（ナレッジ検索 → Gemini）→ Pydanticで形式を検査 → 画面
```

- **回答範囲**: 町丁目ごとの地形、たまりやすい場所、雨水出水浸水想定区域図での想定、過去の浸水、近くの避難所・土のう置場。このマップ自体の仕組み（計算方法、照合結果、使用技術）、画面の使い方、用語の意味も、町丁目の選択なしで回答（例:「流出係数はどう決めた？」「凡例の切り替え方は？」）
- **LLMを呼ばない質問**: 緊急の言葉、避難・安全の判断、現在の状況や予報、対象外の地名、特定できない地名、複数町丁目を含む質問、200字超の質問。バックエンドが定型の回答を返却
- **RAG**: 13文書（地域の背景、町丁目10件、用語とデータの説明、このマップについて）。町丁目10件は町丁目ごとの事実をまとめたJSONからスクリプトで生成し、章立てを統一。1チャンク＝1話題・約500字以内。ハイブリッド検索（セマンティック0.5／キーワード0.5、Top K 5）、埋め込みは gemini-embedding-001
- **出力の検査**: JSON契約（headline、facts、safe_next_steps、prohibited_claim_check など）で検証。契約違反・禁止事項への抵触・タイムアウト時は定型の回答にフォールバック
- 回答の下に続けて聞ける質問（「水がたまりやすい場所」「過去の浸水」「避難所・土のう置場」など）を提示

**7. 制約と既知の課題**

- 下水道の管路網は対象外（一律50mm/h）。個々の管の能力は未反映
- 降雨の時間配分は暫定
- 雨水出水浸水想定区域図のレイヤーはPDFのジオリファレンスによる作成のため、位置に数mの誤差（GCPのRMSE 約4.5m）
