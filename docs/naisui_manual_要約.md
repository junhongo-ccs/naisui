# 「内水浸水想定区域図作成マニュアル（案）」要約

## 文書情報

- 発行: 国土交通省 水管理・国土保全局 下水道部
- 版: 令和3年7月
- 対象: 地方公共団体が作成・公表する内水浸水想定区域図
- 元資料: [naisui_manual.pdf](naisui_manual.pdf)

## このマニュアルの目的

本マニュアルは、集中豪雨で下水道などの排水能力を超えた雨水が市街地にあふれる **内水氾濫** を対象に、想定浸水区域・浸水深・浸水継続時間を示す「内水浸水想定区域図」の作成方法を定めたものです。

ハード整備だけでは防ぎきれない浸水被害を減らすため、住民へのリスク情報の公表・周知を進め、自助・共助・避難行動を促すことを狙いとしています。避難情報などを載せた内水ハザードマップを作成する場合は、別途「水害ハザードマップ作成の手引き」に従います。

## 背景

- 都市化、資産の集中、地下空間利用の進展により、浸水被害の影響が大きくなっている。
- 内水氾濫は、河川の決壊・越水による洪水とは発生場所や仕組みが異なり、発生頻度が高く、豪雨から浸水までの時間が短い。
- 2021年の水防法改正を踏まえ、下水道による浸水対策を実施する全ての地方公共団体で、想定区域図の作成・公表を促進するため内容が拡充された。

## 用語と対象降雨

| 区分 | 内容 |
| --- | --- |
| 内水浸水想定区域 | 排水施設の能力不足や放流先河川等の水位上昇により、雨水を排水できず浸水が想定される区域。実績浸水区域も含む。 |
| L1: 計画降雨 | 下水道計画などで想定する降雨。 |
| L1': 一定の被害が想定される降雨 | 地域の既往最大降雨や、他地域の大規模降雨など。 |
| L2: 想定最大規模降雨 | 水防法に基づく最大規模の外力。これによる区域は「雨水出水浸水想定区域」と呼ばれる。 |

対象降雨は、作図の目的、地域の浸水リスク、既存の計画・浸水実績を踏まえて設定します。L2を用いる場合は、国の「想定最大外力の設定手法」に従い、地域区分・流域面積・流達時間・実績降雨波形などから設定します。

## 作成の流れ

```text
基礎調査
  ↓
排水区域の特徴把握・基本方針の決定
  ↓
対象降雨、放流先水位、対象区域を設定
  ↓
地域に合う内水浸水想定手法を選定
  ↓
浸水区域・浸水深・必要に応じて浸水継続時間を作図
  ↓
公表、活用、施設整備や土地利用の変化に応じた見直し
```

## 事前に集める主なデータ

| データ | 主な用途 |
| --- | --- |
| 降雨・浸水実績 | 対象降雨の設定、モデルの再現性確認 |
| 標高データ（DEM）、マンホール地盤高 | 水の流れ、低地、浸水深の計算 |
| 土地利用・建物・道路等 | 浸透・流出特性、流下を妨げる構造物の把握 |
| 下水道台帳、管きょ、ポンプ場 | 排水系統・排水能力のモデル化 |
| 貯留・浸透施設 | 雨水の貯留・浸透効果の反映 |
| 放流先河川・海域の水位 | 排水先の水位上昇による排水不能の評価 |
| 他の浸水想定区域図 | 洪水・高潮などとの整合、既存データの活用 |

隣接する排水区域・自治体をまたぐ水の移動や、局所的なくぼ地が想定される場合は、必要に応じて現地調査や測量を行います。

## 内水浸水想定の3手法

地域特性、保有データ、浸水実績、施設整備状況に応じて選びます。同一の自治体内でも地区ごとに異なる手法を採用できます。

| 手法 | 向く状況 | 特徴・注意点 |
| --- | --- | --- |
| 浸水シミュレーション | 下水道・地形・降雨などのデータがそろう地域 | 降雨、流出、管きょ、地表氾濫をモデル化できる。詳細だが、データとモデルの精度管理が重要。 |
| 地形情報を活用した手法 | シミュレーションに必要なデータが十分でない地域 | 低地・地形から浸水しやすい区域を推定する。管きょへの流入・溢水などを詳細に扱う結果とは、水深・継続時間が異なり得る。 |
| 浸水実績を活用した手法 | 信頼できる過去の浸水記録がある地域 | 実績をもとに区域を示す。記録が限られる場合、区域を十分に表現できない可能性がある。 |

データが不十分なため簡易手法を採用した場合も、データの充実後に詳細な浸水シミュレーションへ高度化することが求められます。

## 浸水シミュレーションで扱う内容

詳細な解析では、次の要素を組み合わせます。

1. 降雨から地表流出量を算出する。
2. 管きょ・ポンプ場・貯留浸透施設などの排水施設をモデル化する。
3. 放流先河川・海域の水位を境界条件として設定する。
4. 下水道からの溢水と、地表での水の移動・広がりを計算する。
5. 浸水実績などと照合し、必要に応じて再現性を確認する。

耐水化の対象を上回る降雨を評価する場合は、浸水によるポンプ停止など、下水道施設の機能停止を考慮したシナリオも検討します。

## 図面に示す主な情報

- 内水浸水想定区域
- 浸水深
- 必要に応じて浸水継続時間
- 対象降雨、対象区域、作成時点の施設整備状況
- 想定手法、境界条件、利用上の留意事項

図面には、色が付いていない場所でも降雨の状況によっては浸水し得ること、前提を超える降雨・洪水・高潮・津波は評価対象外であることを明記します。想定結果を「浸水しないことの保証」と誤解させないことが重要です。

## 実務上の要点

- 洪水浸水想定区域図とは別に、内水リスクを明示する。両者は発生原因・区域・リードタイムが異なる。
- 想定手法と前提条件を住民に分かる形で示す。地区ごとに手法が異なる場合は、その理由も説明する。
- 下水道整備、貯留・浸透施設、土地利用、排水先河川の状況が変わった場合には、区域図を見直す。
- 区域図を公表して終わりにせず、ハザードマップ、避難情報、地域の防災活動、施設整備の優先順位付けに活用する。
