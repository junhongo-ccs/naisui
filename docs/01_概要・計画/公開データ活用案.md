# 品川区・内水氾濫GIS調査メモ

## 1. 調査目的

品川区を対象に、以下の情報を組み合わせた内水氾濫GISを構築する。

- 浸水深・地盤高
- 過去の浸水実績
- 下水道・排水施設
- 下水道の排除方式
- ポンプ所・水再生センター
- 河川・運河・海岸線
- 道路・建物・土地利用などの都市基盤情報

本調査では、公開されているCSV・GIS・PDF・WebGISを確認し、GIS化の可否、データ精度、利用上の制約を整理した。

> 今回のモデル地域には、水没リスクを検討すべきアンダーパスが存在しないため、アンダーパスに関する表示・分析・データ収集は対象外とする。

***

# 2. 結論

品川区の内水氾濫GISにおいて、最も重要な基盤データは、東京都が公開している以下のデータである。

> **浸水予想区域図（改定）浸水深・地盤高CSV**

このデータに、以下のレイヤーを重ねることで、まずは実用的な試作版を構築できる。

1. 品川区境界
2. 町丁目境界
3. 浸水深・地盤高メッシュ
4. 品川区の過去の浸水実績
5. 下水道の排除方式
6. ポンプ所・水再生センター
7. 河川・運河・海岸線
8. 道路・建物・土地利用
9. 地形・標高・低地・窪地

一方、以下の詳細データは、公開CSV・GISとしては不足している。

- 雨水ますの全位置
- 下水道管きょの中心線
- 管径・管底高・勾配
- マンホールの位置・標高
- 雨水の集水区域
- 排水ポンプの能力・稼働条件
- 雨水ますの閉塞・清掃履歴
- 直近の浸水実績ポイント
- リアルタイム冠水・水位情報

このため、下水道の詳細構造を把握するには、東京都下水道局の下水道台帳WebGIS「SEMIS」を参照し、必要な情報を手動でGIS化する方法が現実的である。

# 4. 最重要データ：浸水深・地盤高CSV

## 4.1 データ概要

東京都オープンデータカタログには、以下のデータセットが掲載されている。

> **浸水予想区域図（改定）浸水深・地盤高**

掲載されている主なリソースには、以下のようなものがある。

- 神田川流域浸水予想区域図（改定）図郭割PDF
- 神田川流域浸水予想区域図（改定）浸水深・地盤高CSV
- 城南地区河川流域浸水予想区域図（改定）浸水深・地盤高CSV
- 城南地区河川流域浸水予想区域図（改定）浸水深・地盤高データ
- その他、東京都区部各流域の浸水深・地盤高データ

品川区では、主に**城南地区河川流域**のデータを確認する必要がある。

## 4.2 想定降雨

品川区の浸水ハザードマップでは、想定最大規模降雨として以下が示されている。

```text
総雨量：690 mm
時間最大雨量：153 mm
```

この浸水想定は、河川氾濫だけでなく、下水道の排水能力を超えた雨水、窪地への雨水滞留などを含む。

## 4.3 ダウンロード後に確認すべき項目

CSVを入手したら、最初に次の項目を確認する。

- 緯度・経度の有無
- メッシュコードの有無
- 座標系
- 測地系
- 浸水深の単位
- 地盤高の単位
- 欠損値
- 浸水なしの表記
- メッシュの形状
- メッシュ中心点か、メッシュポリゴンを再構成できる形式か
- 品川区全域をカバーしているか
- 流域境界付近の重複・欠落
- 想定降雨条件
- 作成年度・更新日

## 4.4 QGISでの基本処理

### CSVが緯度・経度を持つ場合

1. QGISで「テキストデータソースを追加」
2. Xフィールドに経度を指定
3. Yフィールドに緯度を指定
4. CRSを確認
5. GeoPackageまたはGeoParquetへ保存
6. 浸水深を段階色で表示
7. 品川区境界でクリップ

### メッシュコードだけの場合

1. メッシュコードの仕様を確認
2. 国土地理院のメッシュポリゴンを取得
3. メッシュコードで結合
4. 浸水深・地盤高を属性として付与
5. 品川区境界でクリップ

### 表示分類例

```text
0.00 m：浸水なし
0.01〜0.10 m：10 cm未満
0.10〜0.50 m：0.5 m未満
0.50〜1.00 m：1.0 m未満
1.00〜2.00 m：2.0 m未満
2.00〜3.00 m：3.0 m未満
3.00〜5.00 m：5.0 m未満
5.00 m以上
```

分類区分は、元データの凡例に合わせて変更すること。

# 5. 品川区の浸水ハザードマップ

## 5.1 内容

品川区は、浸水に関するハザードマップと浸水実績を公開している。

主な用途は以下のとおり。

- 浸水範囲の確認
- 想定浸水深の確認
- 避難所・避難場所との関係確認
- 町丁目単位のリスク説明
- 東京都の浸水予想区域図との比較

## 5.2 注意点

品川区の説明によれば、浸水ハザードマップは、以下のような現象を含む。

- 河川からの氾濫
- 下水道管の能力を超えた雨水
- 窪地への雨水滞留
- 道路上の雨水流出

また、落ち葉などによる雨ますの閉塞は、シミュレーションに十分反映されない可能性がある。

さらに、ハザードマップは特定時点の下水道整備状況をもとに作成されているため、以下の現況差に注意する。

- 下水道整備後の変更
- 道路形状の変更
- 建物・土地利用の変化
- 大規模開発
- ポンプ施設の更新
- 雨水流出条件の変化

## 5.3 GIS化方法

PDFしかない場合は、以下の方法を使う。

### 方法A：公式CSVを優先する

東京都の浸水深・地盤高CSVがある場合、PDFのデジタイズよりCSVを優先する。

### 方法B：PDFをジオリファレンス

1. PDFを画像化
2. QGISのジオリファレンサーで基準点を指定
3. 座標系を設定
4. ラスタとして保存
5. 必要に応じて浸水区分をポリゴン化

### 方法C：凡例区分を手動デジタイズ

浸水深の境界線をポリゴン化し、以下の属性を付与する。

```text
depth_class
depth_min_m
depth_max_m
scenario
source
source_date
digitized_by
digitizing_accuracy
```

# 6. 品川区の浸水実績

## 6.1 公開内容

品川区は、平成元年以降の浸水実績を「町丁別浸水実績一覧」として公開している。

この情報は、次の分析に利用できる。

- 町丁目別の浸水発生頻度
- 浸水実績と想定浸水深の比較
- ハザードマップで想定されていない浸水の確認
- 低地・窪地との関係
- 豪雨時の被害集中地域の把握

## 6.2 精度上の制約

品川区の公開説明では、浸水実績は区への報告および現地調査に基づく。

また、個人情報保護のため、公開範囲は町丁目までである。

したがって、浸水実績をGIS化する際には、次のように扱う。

### 推奨

- 町丁目ポリゴンに集計値を結合
- 件数を色分け
- 年代別に表示
- 浸水種別を可能な範囲で区分

### 非推奨

- 町丁目の代表点を実際の浸水地点として表示
- 住所を推定してポイント化
- 個別住宅を特定できる形で表示

## 6.3 推奨属性

```text
district_code
district_name
year
period
above_floor_count
below_floor_count
total_count
source
source_note
geometry
```

位置情報を町丁目単位で保持する場合は、属性名に以下のような注意書きを加えるとよい。

```text
spatial_accuracy = "chomoku_level"
```

# 7. 下水道台帳WebGIS「SEMIS」

## 7.1 概要

東京都下水道局は、下水道台帳情報をWebGISで公開している。

```text
システム名：SEMIS
提供元：東京都下水道局
用途：下水道台帳情報の閲覧
```

確認できる可能性がある情報は、以下のとおり。

- 下水道管きょ
- マンホール
- 下水道施設
- 管路の種別
- 管径
- 下水道の配置
- 周辺道路との位置関係
- ポンプ所・処理施設等

## 7.2 利用上の制約

SEMISの情報は、以下の点に注意する。

- 現地を正確・詳細に測量した図面ではない
- 工事後の変更が反映されていない可能性がある
- 現況と図面が一致しない場合がある
- 宅地内・私道の排水設備は原則対象外
- 一部の情報は窓口閲覧が必要な可能性がある
- 画像・図面の二次利用条件を確認する必要がある
- 一括ダウンロード可能なオープンデータとは限らない
- 設計・工事・安全判断には現地確認が必要

## 7.3 GISでの現実的な使い方

SEMISは、直接APIやCSVで取り込むより、次の用途に使うのが現実的である。

1. モデル地域周辺の管路を目視確認
2. 雨水管・合流管の位置を確認
3. マンホール・雨水ますの配置を確認
4. 幹線・ポンプ所との接続関係を確認
5. 背景画像や既存GISと比較
6. 必要な範囲だけ手動デジタイズ
7. 出典・閲覧日・位置精度を属性に記録

## 7.4 SEMIS由来データの属性例

```text
source = "Tokyo Sewerage Bureau SEMIS"
source_access_date = "YYYY-MM-DD"
digitizing_method = "manual_digitizing"
geometry_accuracy = "approximate"
reuse_permission = "to_be_confirmed"
field_verification = false
notes = "Reference-only; not for construction design"
```

# 8. 下水道の排除方式

## 8.1 利用可能な情報

東京都下水道局は、23区の公共下水道の普及状況として、以下を公開している。

- 告示一覧表
- 告示現況図

品川区についても、住所ごとの公共下水道の告示状況や、下水道区域の現況を確認できる。

## 8.2 GISで確認したい区分

内水氾濫の分析では、次の区分が重要である。

```text
合流式区域
分流式区域
雨水除外区域
公共下水道未供用区域
その他・不明
```

## 8.3 排除方式が重要な理由

同じ降雨量でも、排除方式によって雨水の流れや下水道負荷が変わる。

### 合流式区域

- 汚水と雨水を同じ管で処理
- 大雨時に管路負荷が高くなりやすい
- 下水道能力超過時の浸水と関係する可能性がある

### 分流式区域

- 汚水管と雨水管を分離
- 雨水は雨水管や水路等で排除
- 雨水管側の能力や流下先が重要になる

### 雨水除外区域

- 雨水を下水道管に流さない区域
- 海・運河・水路等への排除構造を確認する必要がある
- 下水道だけでは浸水リスクを評価できない場合がある

## 8.4 属性例

```text
zone_id
drainage_type
rainwater_excluded
sewer_service_status
source
source_date
geometry
notes
```

# 9. 国土数値情報「下水道関連施設」

## 9.1 概要

国土数値情報の「下水道関連施設」データは、下水道関連施設として、主に以下を収録する。

- 処理場
- ポンプ場

形式はGMLまたはShapeで提供される。

## 9.2 制約

現在確認できるデータは、2012年度版である。

そのため、以下の点に注意する。

- 施設の新設・廃止が反映されていない可能性
- 最新の名称と一致しない可能性
- 位置精度が詳細な下水道台帳より低い可能性
- 管路・マンホール・雨水ますは対象外
- 品川区の小規模な排水施設を網羅しない可能性

## 9.3 利用方法

このデータは、詳細な下水道解析よりも、次の用途に向いている。

- ポンプ所・処理場の概略位置
- 区全体の下水道施設分布
- 浸水深メッシュとの距離分析
- 都市インフラの概況図
- 他のデータと重ねるための補助レイヤー

# 10. 東京都下水道局の工事情報CSV

東京都下水道局は、下水道工事情報をCSVで公開している。

利用できる可能性がある情報は、以下のとおり。

- 工事場所
- 工事件名
- 工事期間
- 工事概要
- 施工・管理主体
- 道路通行への影響

## GISでの用途

下水道工事情報は、浸水解析の直接データではないが、次の用途に使える。

- 下水道施設更新の履歴確認
- 浸水リスクの高い地域での改修状況確認
- 古いデータと現況の差の把握
- 下水道施設の更新時期の把握
- 将来のデータ更新管理

## 注意点

工事情報は、下水道管の全体構造や排水能力を表すデータではない。

したがって、工事の有無だけから、以下を断定してはいけない。

- 浸水リスクが解消された
- 排水能力が向上した
- 雨水排除能力が改善された
- 下水道管の容量が増えた

# 13. 品川区GISの分析例

## 13.1 町丁目別の浸水実績と地盤高

目的：

> 過去の浸水実績が多い町丁目と低地の関係を確認する。

処理手順：

1. 町丁目境界を用意
2. 地盤高メッシュを町丁目単位で集計
3. 町丁目別浸水実績を結合
4. 浸水実績件数を面積または人口で正規化
5. 高低差・土地利用・道路密度と比較

推奨指標：

```text
total_inundation_records
records_per_km2
mean_ground_elevation_m
minimum_ground_elevation_m
flood_depth_max_m
flood_depth_mean_m
```

## 13.2 下水道排除方式と浸水深

目的：

> 合流式・分流式・雨水除外区域で浸水リスクに差があるか確認する。

処理手順：

1. 排除方式ポリゴンを用意
2. 浸水深メッシュと交差
3. 排除方式ごとの浸水深統計を作成
4. 浸水実績と比較
5. 町丁目単位またはメッシュ単位で可視化

注意：

- 浸水深の違いを排除方式だけで説明しない
- 標高、土地利用、河川・運河までの距離、雨水流出量などを併せて考慮する
- ハザードマップのシナリオ条件を統一する

## 13.3 地形・低地・窪地の分析

目的：

> 地盤高や地形条件から、雨水が滞留しやすい地域を把握する。

利用候補：

- 地盤高
- 標高差
- 傾斜
- 凹地・窪地
- 道路縦断
- 建物密度
- 不浸透面積率
- 河川・運河からの距離

簡易的には、以下のような指標を作成できる。

```text
topographic_lowland_score
depression_score
impervious_surface_score
distance_to_waterbody_m
```

これらは分析補助用の相対指標であり、公式な浸水予測値ではない。

# 18. リスク評価指標の試作例

地域単位またはメッシュ単位で、以下の指標を使って簡易的な相対評価を作成できる。

```text
risk_score =
    flood_depth_score
  + low_elevation_score
  + past_inundation_score
  + drainage_uncertainty_score
  + impervious_surface_score
```

ただし、各スコアは可視化・比較用の相対評価とし、公式な安全判断や避難判断には使用しない。

## 推奨属性

```text
flood_depth_score
low_elevation_score
past_inundation_score
drainage_uncertainty_score
impervious_surface_score
risk_score
risk_class
confidence_level
```

下水道管路や排水施設の情報が不足している場合は、リスクスコアだけでなく、信頼度も低く設定する。

```text
confidence_level = "high"
confidence_level = "medium"
confidence_level = "low"
```

# 19. データ利用上の重要な注意

- ハザードマップの浸水深は、特定の降雨シナリオに基づく想定値であり、実際の浸水深と常に一致するわけではない。
- 浸水実績がないことは、浸水リスクがないことを意味しない。
- 町丁目単位の浸水実績を、個別地点の浸水として表示してはいけない。
- SEMISの図面を設計・工事・避難判断に直接利用しない。
- 下水道管の有無だけで排水能力を判断しない。
- ポンプ所の位置だけで、特定地域の排水能力を断定しない。
- 公開データの更新年度を必ず表示する。
- 異なる想定降雨・作成年度のデータを、同一条件として比較しない。
- PDFの再配布・画像利用・デジタイズデータの公開については、各データの利用規約を確認する。
- 現地確認が必要な情報には、`unverified` または `reference_only` のフラグを付ける。
- モデル地域の対象外となる地物やリスク要因は、初期GISの表示・分析対象に含めない。
